# Exports et partage

## Rapports PDF

Chaque atelier validé produit un **rapport PDF** dédié (menu **Rapports** de
l'étude, ou bouton de téléchargement dans l'atelier) :

- Atelier 1 : identité, valeurs métier, biens support, événements redoutés,
  écart de socle.
- Atelier 2 : couples SR/OV et pertinence.
- Atelier 3 : radar de l'écosystème, arbre des scénarios, chemins d'attaque.
- Atelier 4 : modes opératoires, actions par phase, techniques MITRE,
  vraisemblance.
- Atelier 5 : plan de traitement, grille de risque, cartographie résiduelle.
- **Annexe de conformité** : tableau de couverture ISO 27001 ou NIS2.

## Exports bureautiques

Depuis le **tableau de bord** de l'étude :

- **Registre des risques (Excel)** : classeur à cinq feuilles — Synthèse,
  Scénarios de risque, Plan de traitement, Écosystème, Conformité. État courant
  (pas figé à un *snapshot*). Filtres automatiques, colonnes ajustées.
- **Synthèse (Word)** : document `.docx` éditable — identité, chiffres clés,
  registre des risques, plan de traitement. Utile pour intégrer l'analyse dans
  un rapport plus large.

Depuis le **portefeuille** : export Excel multi-études.

## Export / import JSON

- **Exporter une étude** produit un fichier JSON complet (tous les ateliers).
- **Importer une étude** recrée l'étude sur une autre installation ou un autre
  compte à partir de ce fichier. Les cinq ateliers repartent à l'état
  brouillon ; les clés internes sont ré-attribuées.
- **Dupliquer une étude** fait la même chose en interne, sans passer par un
  fichier — pratique pour créer un modèle réutilisable.

## Multi-langue

Le sélecteur **FR / EN** (menu **Paramètres**) traduit l'ossature de
l'interface (navigation, en-têtes des vues transverses). Le contenu
méthodologique détaillé des ateliers et les rapports PDF restent en français.

## Partage d'une étude

Menu **Membres** de l'étude : invitez un compte par e-mail et attribuez un
rôle (Lecteur, Éditeur, Propriétaire). Voir le guide *Prise en main* pour le
détail des rôles et le journal d'audit.
